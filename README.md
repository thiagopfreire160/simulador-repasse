# Simulador de Repasse

Aplicação estática em HTML para simulação de repasses.

## Publicação no GitHub Pages

O workflow em `.github/workflows/deploy-pages.yml` publica automaticamente o conteúdo do repositório no GitHub Pages sempre que houver um push na branch `main`.

Na primeira publicação, habilite **Settings → Pages → Build and deployment → Source: GitHub Actions**. Depois, a URL do site ficará disponível na página do workflow ou em **Settings → Pages**.
